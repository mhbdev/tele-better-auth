# Code of conduct

Contributors and users should treat each other with respect. We welcome constructive feedback, different perspectives and participation across experience levels.

Harassment, discrimination, threats, unwanted sexual attention, personal attacks and publishing private information without consent are unacceptable.

Maintainer [mhbdev](https://github.com/mhbdev) may remove inappropriate content or restrict participation. Report concerns privately using GitHub's reporting tools. Do not include private personal information in public issues.

This policy is informed by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
