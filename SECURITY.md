# Security policy

The latest 1.7.x release receives security fixes. Upgrade older releases before reporting behavior that has already been corrected.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/mhbdev/tele-better-auth/security/advisories/new). Include the affected version, reproduction steps, expected and actual behavior, and impact. Do not publish credentials or raw authentication payloads.

Maintainer: [mhbdev](https://github.com/mhbdev). Reports are investigated privately and coordinated fixes are documented in release notes.

See the [security guide](./docs/security.md) for verification, identity, linking, replay and deployment behavior.
